# What a bot receives

Generated by `pokelike schema --markdown` from a real observation, so it
cannot describe a game that no longer exists. Regenerate it after any
change to `core/bridge.js`.

```
==============================================================================
  WHAT A BOT RECEIVES
==============================================================================

  choose(state) -> int      returns an index into state['actions']

  One state, not a history. The history that matters is already inside:
  every node carries `visited`, and `stats` are cumulative from the start
  of the run.

------------------------------------------------------------------------------
TOP LEVEL
------------------------------------------------------------------------------
  actions      THE LEGAL MOVES. choose() returns an index into this list
  bag          item names you are carrying
  can_reorder  whether the team can be reordered right now. Slot 0 leads the next battle, so the order is a decision — but a FREE one, which is why it is not in `actions`: see Bot.rearrange / Game.reorder
  done         True when the run is over
  layer        'screen' or 'modal' — modals are choices too, not decoration
  map          the whole board: nodes, edges, where you stand
  prompt       what the screen is ASKING. Read it: on the swap screen the same list of your team means 'choose one to release', not 'choose a lead'
  run          run-wide facts: map index, badges, whether anyone has fainted
  screen       which screen you are on: map-screen, catch-screen, item-equip-modal, ...
  seed         the run's seed; the same seed replays the same run
  stats        the engine's cumulative counters, updated after every battle
  steps        how many decisions this run has taken
  team         your Pokemon, in order. Everything about them

------------------------------------------------------------------------------
state['actions']  —  THE ONLY THING YOU MUST UNDERSTAND
------------------------------------------------------------------------------
  Between 2 and 7 entries. They change every turn, and they are NOT stable
  by position: index 2 is a battle now and a catch next turn.

  Two shapes:

  a map move                      any other choice
    kind:  'node'                   kind:  'element'
    id:    'n3_1'                   idx:   2
    node:  'catch'                  label: 'Squirtle Lv. 5 WATER ...'
    layer: 3                        layer: 'catch-screen'
    col:   1

  real: {"kind": "node", "id": "n3_0", "node": "catch", "layer": 3, "col": 0}
  real: {"kind": "node", "id": "n3_1", "node": "catch", "layer": 3, "col": 1}

  node kinds you will meet:
    start        where the map begins
    catch        adds a Pokemon to your team
    battle       one wild Pokemon
    trainer      1 Pokemon on map 0, 2 on maps 1-2, 3 from map 3 onwards
    item         pick one of three items
    pokecenter   restores HP
    question     unknown until you enter it (shown as `unknown` in logs)
    boss         the gym leader at the bottom of the map
    trade        trade a Pokemon
    move_tutor   teach a move
    pokemart     buy something
    shiny        a shiny encounter

------------------------------------------------------------------------------
state['run']
------------------------------------------------------------------------------
  anyone_fainted   whether anything has fainted this run
  badges           gym badges earned. This is the progression metric in Story mode
  elite            Elite Four progress
  finished         engine's own end-of-run flag
  items_this_run   items picked up
  map              which map you are on, 0-indexed
  max_team_size    high-water mark of team size, NOT a limit (the limit is 6)
  nuzlocke         whether nuzlocke rules are on
  run_seed         the engine's internal seed for this run

------------------------------------------------------------------------------
state['team'][i]
------------------------------------------------------------------------------
  base_stats     hp, atk, def, speed, special, spdef
  hp             current HP
  item           held item name, or null
  level          current level
  max_hp         maximum HP. hp/max_hp is what tells you if it is in danger
  mega_stone     held mega stone, or null
  move_tier      which tier of moves it knows
  name           species name, e.g. 'Bulbasaur'
  shiny          whether it is shiny (worth points at the end)
  species_id     national dex number
  types          list of types, e.g. ['Grass', 'Poison'] — this decides battles
  uid            unique id within the run

------------------------------------------------------------------------------
state['map']
------------------------------------------------------------------------------
  current    id of the node you are standing on
  edges      [from, to] pairs. This is how you know where a choice leads
  nodes      every node: id, kind, layer, col, accessible, visited, revealed

  Picking a node CLOSES every other node on that layer, forever. Use
  `edges` to see where a choice leads before taking it.

------------------------------------------------------------------------------
state['stats']  —  the engine's own counters, for building a reward
------------------------------------------------------------------------------
    battlesWon
    catches
    contrib
    critHits
    damageHealed
    damageTakenPreResist
    enemiesKO
    faintsSuffered
    highestHit
    highestHp
    highestLevel
    mapsCleared
    mostDamageOneBattle
    startTime
    superEffectiveHits
    totalDamageDealt
    totalDamageTaken

  Cumulative and updated after every battle, so a per-step reward is the
  difference between two consecutive observations.

------------------------------------------------------------------------------
WHAT IS NOT IN HERE
------------------------------------------------------------------------------
  * which item you were offered and refused on a node you skipped
  * what a '?' node will turn into, before you enter it
  * the enemy team, before the battle starts
  A human player does not know these either.

  Also absent on purpose: any reward. Reward is a training signal, and it
  belongs to whatever is learning, not to the state. See
  experiments/env/rewards.py.
```
